## RISKS
| # | Risk | Evidence | Severity | Mitigation (proposed; decided in Phase 1 ADRs) |
|---|---|---|---|---|
| R1 | Host ports 5432 and 6379 are already bound by another project's Postgres/Redis. A default compose file would fail to start or, worse, the app could connect to the wrong database. | L78–L79, L180–L181 | MAJOR | OmniGrowth compose publishes on non-default host ports (e.g. 55432 / 56379) and uses a dedicated compose project name; `DATABASE_URL` is always explicit. |
| R2 | `OPENAI_API_KEY` is set in the user environment. If the cloud adapter auto-enables on "any key present" (A1), private content could route to a cloud provider without deliberate opt-in. | L192 | MAJOR | Cloud adapter reads only `OMNIGROWTH_`-prefixed keys; default profile `LOCAL_ONLY` (A2). |
| R3 | Ollama lists `deepseek-v3.1:671b-cloud`, a model name suggesting Ollama proxies it to a remote service. Routing a `*_local` role to it would violate §52 privacy while *looking* local. | L165 | MAJOR | Router treats the model, not the provider preset, as the privacy boundary: models matching a configurable deny pattern (default `*-cloud`, `*:cloud`) are classified `remote`. |
| R4 | GPU already 9.9 / 12.2 GB used with `llama-server` resident. A second model load (e.g. embeddings + generation) may OOM or thrash. | L97, L142, L147 | MINOR | A2 `max_concurrency: 1`; embeddings role defaults to a small model; health check reports degraded, not failed. |
| R5 | `ANTHROPIC_BASE_URL` is set in the environment; an SDK-based adapter would silently pick it up and send traffic somewhere other than the default endpoint. | L187 | MINOR | Cloud adapter takes base URL from OmniGrowth config only, passed explicitly. |
| R6 | Repo is on NTFS (`C:\dev`) and Docker Desktop uses the WSL2 backend; bind-mount hot reload may be slow (A10). | L3, L58 | MINOR | Record only; do not move repo without asking. Measure in Phase 2. |
| R7 | Other agent containers (`hermes-*`) are running on the same Docker engine. | L74–L76 | INFO | Use a unique compose project name `omnigrowth`; never run `docker compose down` without `-p omnigrowth`. |
| R8 | Python 3.12.0 is an early patch release. | L32 | INFO | Pin `requires-python = ">=3.12"` and let uv use 3.13.6; CI tests on 3.12 and 3.13. |
